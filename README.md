## Topics explored

- IPOS, hardware, software and everyday computer-based systems
- Safe Terminal file operations, flags and pipes
- Processes, paths, storage and permissions
- Compiler and interpreter concepts
- Decimal, binary and hexadecimal conversions
- Character encoding and text storage
- Git staging, commits, branches and Pull Requests
- LAN, MAN, WAN, DNS, routers and networking protocols

## Run the number converter

From the project root:

```sh
python3 mission-05-numbers-data/number_converter.py
```

Enter a positive decimal integer when prompted. The program prints that value in binary and hexadecimal.

## Learning summary

This project demonstrates how computer components and software work together, how operating systems manage programs and files, and how data is converted and stored. It also records a practical introduction to command-line tools and collaborative version control.

Each mission was documented separately and received a dedicated Git commit. Personal details, passwords, access tokens and private network information are not included.

## My Learning

- The operating system coordinates hardware, memory, processes, files and permissions, allowing applications to run reliably.
- Git makes project changes reviewable through staging and commits, while branches and Pull Requests provide a controlled way to collaborate on separate updates.
