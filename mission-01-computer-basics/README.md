### Task 1.1 — IPOS trace: typing and saving a document

| Stage | What happens | Hardware / component |
|---|---|---|
| Input | I press keys and the text editor receives characters. | Keyboard |
| Processing | The processor and memory turn the text input into data and update the open document. | CPU and RAM |
| Output | The text appears on the display so I can review it. | Screen / monitor |
| Storage | Selecting Save writes the document to persistent storage. | SSD and, if used, cloud storage |

The activity begins with keyboard input. The editor processes the characters and temporarily holds the document in memory, shows the result on screen, and finally saves it to an SSD or cloud storage.

## 4. My understanding

IPOS describes a useful cycle: a system receives input, processes it, provides output and preserves results when storage is needed. Hardware is the physical equipment, while software gives hardware instructions. Operating systems manage resources, applications help users perform tasks and utilities help maintain or protect the system.
